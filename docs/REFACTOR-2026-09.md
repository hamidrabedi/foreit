# Refactor, September 2026

A cleanup of the Go framework under `forge/`: critical bug fixes, removal of code that was broken or duplicated, design fixes, and splits of very large files. Features that worked were kept; where a feature was broken it was fixed or made to fail loudly instead of silently doing nothing.

## What changed

| Area | Change | PRs |
|---|---|---|
| ORM | to-many filters no longer duplicate rows; writes use schema column names and the schema primary key; quoted identifiers in write SQL; `Exists` uses `LIMIT 1`; many-to-many through columns follow `<model>_id`; unfinished set operations and aggregates return a not-implemented error | #215, #217, #225, #229 |
| ORM | transactions (`Manager.WithTx`); placeholders generated by the dialect (no rewriting inside string literals); relation columns resolved once at schema build; one expression rendering path; `queryset.go` split by responsibility | #231 |
| Admin | create/update only write editable fields; staff and superuser accounts can log in through `identity` (environment credentials remain as a fallback); history store race fixed; large files split | #218, #229, #231 |
| API | JSON `null` no longer panics; absolute pagination links; permission checks match real user fields; unknown tokens are rejected; multipart boundary, ordering and search filters fixed; one viewset (`BaseViewSet` with authentication, permission and throttle classes); custom actions via `Router.Action`; one error format (RFC 7807) with a custom mapper hook; one rate-limit package with fixed-window API throttles and a pluggable `Store` | #221, #222, #229, #230 |
| Auth | password backend no longer reveals whether an account exists or is inactive; cookie session auth on unsafe methods requires CSRF middleware | #219, #231 |
| Migrations | SQLite DDL for foreign keys and dropped columns; status reports only real versions; the generator no longer creates golang-migrate's table; removing a model or field no longer aborts generation; `MigrationRunner.RollbackSteps` | #223, #224, #227, #230 |
| CLI | superuser password is read without echo; `forge test` runs `go test`; configuration is loaded once | #229, #230, #231 |
| Not implemented yet (fail loudly) | database idempotency store, remote log output, `migrations squash`, registry admin/API plugin extensions | #220, #230 |

## Breaking changes and migration

| Removed or changed | Use instead |
|---|---|
| `api.EnhancedBaseViewSet`, `EnhancedBaseViewSetIntegrated`, `CreateDefaultViewSet`, `CreateProductionViewSet`, `RegisterAPIWithDefaults`, `CompleteExample` (their create, retrieve, update and delete never worked) | `api.BaseViewSet` / `api.ViewSetConfig` with `Authentication`, `Permissions`, `Throttles`, `ErrorWriter` |
| `api.EnhancedRouter`, `ActionRegistry`, `RegisterAction`, `RegisterEnhanced`, `RegisterRoutesEnhanced` | `api.Router.Action(resource, name, ActionConfig, handler)`; OPTIONS is served per resource |
| `api/exceptions.HandleExceptionHTTP`, `ExceptionHandler`, `DefaultExceptionHandler`, `SetExceptionHandler`, `GetExceptionHandler`, `ErrorResponse`, `APIException.ToResponse`; `api.SetExceptionHandler` | `api/errors.WriteError`, or `errors.NewWriter(&HandlerConfig{CustomMapper: ...})`; exception constructors are unchanged |
| API error body `{error, code, message}` | RFC 7807 `application/problem+json` |
| `throttling.NewUserRateThrottle(rate, cache)`, `NewAnonRateThrottle(rate, cache)`, `CacheBackend`, `MemoryCache` | `NewUserRateThrottle(rate)` (same fixed-window behaviour) or `NewUserRateThrottleWithStore(rate, store)` |
| `db/migrate/execute.Executor`, `NewExecutor`, `RollbackManager`, `RollbackOptions` (duplicates) | `db.NewMigrationRunner`, `RollbackSteps(n)` |
| `filter.FilterCache`; `filter.DialectAdapter` and its adapters (they interpolated values into SQL) | none; use `orm` expressions |
| `server.XSS.SanitizeHTML`, `SQLInjection.ValidateInput`, `SQLInjection.EnsureParameterized` (bypassable) | `html/template` escaping, parameterized queries; `XSS.EscapeHTML`, `SanitizeHTMLStrict` and `SanitizeInput` remain |

Exported signatures that gained parameters keep their original form; the new form has a new name: `cli/core.NewContextWithConfig`, `migrate.GenerateForDriver`, `migrate.NewGeneratorForDriver`, `generate.NewMigrationGeneratorForDriver`, `orm.BuildInsertSQLForPK`, `orm.Execute*Tx`. The deprecated `orm.FieldExpr` / `QueryExpr` API remains until v2.0.

## Open decisions for maintainers

- An explicit application object instead of package-level registries (a public API redesign; the registries are already synchronized).
- Generated scanners instead of reflection in the ORM and viewsets.
- Moving the admin list's lookup parsing onto `forge/filter` (the two accept different lookups today).
- Shrinking the exported `Dialect` interface.
- Wiring `forge/filter` features (saved filters, typed builder, relation depth guard, query planner) into admin and API list views.
- Library changes (for example schema diffing with Atlas) are not planned; logging stays on zap.
