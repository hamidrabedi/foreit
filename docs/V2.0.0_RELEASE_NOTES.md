# Release Notes: v2.0.0 - Naming Consistency Improvements

**Release Date**: 2026-01-01  
**Status**: Ready for Release

## Overview

v2.0.0 continues the naming improvements started in v1.5.0, focusing on consistency, Go idiom compliance, and clarity. All changes maintain backward compatibility through deprecation warnings.

## What's New

### Improved Naming (5 High-Priority Fixes)

1. **`RebindPlaceholders()`** - Clearer name for database placeholder conversion
   ```go
   // Old
   sql := db.Rebind(query)
   
   // New
   sql := db.RebindPlaceholders(query)
   ```

2. **`Global()`** - Access registry without redundant package name
   ```go
   // Old
   registry := registry.GetRegistry()
   
   // New
   registry := registry.Global()
   ```

3. **`Asc()` / `Desc()`** - Preferred over `NewOrderField()`
   ```go
   // Old
   qs.OrderBy(orm.NewOrderField("created_at", true))
   
   // New
   qs.OrderBy(orm.Asc("created_at"))
   ```

4. **`FieldAccessor()`** - Go-conventional getter (no Get prefix)
   ```go
   // Old
   fa, err := manager.GetFieldAccessor()
   
   // New
   fa, err := manager.FieldAccessor()
   ```

5. **`ParsePaginationParams()`** - Clearer intent (parsing vs getting)
   ```go
   // Old
   page, size, offset := api.GetPaginationParams(r, 20)
   
   // New
   page, size, offset := api.ParsePaginationParams(r, 20)
   ```

## Breaking Changes

**None in v2.0.0** - All changes are backward compatible with deprecation warnings.

## Deprecations

The following functions are deprecated and will be removed in v3.0:

1. **`Rebind()`** - Use `RebindPlaceholders()` for clarity
2. **`GetRegistry()`** - Use `Global()` to avoid package name redundancy
3. **`NewOrderField()`** - Use `Asc()` or `Desc()` for clarity
4. **`GetFieldAccessor()`** - Use `FieldAccessor()` (Go convention: no Get prefix)
5. **`GetPaginationParams()`** - Use `ParsePaginationParams()` for clarity

**Migration Period**: 6 months (v2.0.0 → v3.0.0)

## Migration Guide

### Automated Migration

Use the provided migration script:

```bash

```

This automatically updates:
- `Rebind()` → `RebindPlaceholders()`
- `GetRegistry()` → `Global()`
- `GetFieldAccessor()` → `FieldAccessor()`
- `GetPaginationParams()` → `ParsePaginationParams()`

**Note**: `NewOrderField()` requires manual review (true/false → Asc/Desc)
