# Archived Documentation
This folder preserves the historical markdowns that powered the previous `docs/` index. The canonical reference is now [`docs/FOREIT_GUIDE.md`](../FOREIT_GUIDE.md); use the archive only if you need the deeper writeups or older breakdowns that were condensed.

## What’s inside
- **Architecture & Design** (`ARCHITECTURE.md`, `FRAMEWORK_ARCHITECTURE.md`, `NAMING_*`, `CODE_STRUCTURE.md`, `API_ARCHITECTURE.md`, etc.)
- **Getting started, usage, and implementation** (`GETTING_STARTED.md`, `USAGE_GUIDE.md`, `PROJECT_STRUCTURE.md`, `REST_API.md`, `INTEGRATION_GUIDE.md`, `FEATURES.md`, `ROADMAP.md`)
- **Packages** (`pkg_admin_*`, `pkg_users_*`)
- **System & testing notes** (`DEVELOPMENT.md`, `LINTING.md`, `TESTING_*`, `AUTO_DISCOVERY.md`, `CHANGELOG.md`, `MIGRATION_*`, etc.)
- **Docs-new snapshots** are preserved under the `docs-new/` directory for any design notes that hadn’t migrated.

The archive is sorted alphabetically; feel free to search individual files for the specifics that the new guide leaves out.
