# Release Notes: v1.5.0 - Naming Refactor & API Improvements

**Release Date**: 2026-01-01  
**Status**: Ready for Release

## Overview

v1.5.0 introduces significant improvements to the query expression API with clearer naming conventions, better Go idioms, and explicit alternatives for all operations. This release maintains backward compatibility while preparing for v2.0 breaking changes.

## What's New

### 1. New Query Expression API

**Boolean Combiners** - Explicit, clear functions:
```go
// And - combine expressions with AND
qs.Filter(And(
    User.Name.Eq("John"),
    User.Age.Gt(18),
))

// Or - combine expressions with OR
qs.Filter(Or(
    User.Age.Gt(18),
    User.Role.Eq("admin"),
))

// Not - negate an expression
qs.Exclude(Not(User.Age.Gt(65)))
```

**Runtime Field References** - For dynamic queries:
```go
// Django-style (short)
qs.Filter(F("age").Gt(18))

// Explicit alternative
qs.Filter(FieldRef("age").Gt(18))

// SQL-like Where clause
qs.Filter(Where("age", OpGreater, 18))
```

### 2. Field Type Consolidation

- `FieldExpression[T]` → `Field[T]` (backward-compatible alias provided)
- Deprecated `FieldExpr[T]` in favor of `Field[T]`
- Shorter method names: `Eq()`, `Gt()`, `Gte()`, `Lt()`, `Lte()`, `Ne()`

### 3. Enhanced Documentation

- Comprehensive naming architecture documentation
- Migration guide for v1.x → v2.0
- Updated API reference with new examples
- Clear Get() semantics documentation

## Breaking Changes

**None in v1.5.0** - All changes are backward compatible with deprecation warnings.

## Deprecations

The following functions are deprecated and will be removed in v2.0:

1. **`NewQ()`** - Use `And()`, `Or()`, `Not()` directly
2. **`NewFieldQueryExpr()`** - Use `Where()` or field methods
3. **`FieldExpr[T]`** - Use `Field[T]` (via `NewField`)
4. **`NewFieldExpr()`** - Use `NewField()`

**Migration Period**: 6 months (v1.5.0 → v2.0.0)

## Migration Guide

See [MIGRATION_V1_TO_V2.md](./MIGRATION_V1_TO_V2.md) for detailed migration instructions.

### Quick Migration Examples

**Before**:
```go
q := orm.NewQ(nameField.Eq("John"))
qs.Filter(q)
```

**After**:
```go
qs.Filter(nameField.Eq("John"))  // Direct (simplest)
// Or for complex queries:
qs.Filter(And(nameField.Eq("John"), ageField.Gt(18)))
```
