# Refine Integration for Gogo

This package provides a Refine data provider for connecting Refine-based React admin panels to the Gogo admin engine backend.

## Installation

```bash
npm install @refinedev/core
# or
yarn add @refinedev/core
```

## Usage

### Basic Setup

```typescript
import { Refine } from "@refinedev/core";
import { gogoDataProvider } from "./dataProvider";

function App() {
  return (
    <Refine
      dataProvider={gogoDataProvider({
        apiUrl: "http://localhost:8080/admin/api",
        getAccessToken: () => {
          // Return your auth token from storage
          return localStorage.getItem("token");
        },
      })}
      resources={[
        {
          name: "users",
          list: "/users",
          create: "/users/create",
          edit: "/users/edit/:id",
          show: "/users/show/:id",
        },
        {
          name: "articles",
          list: "/articles",
          create: "/articles/create",
          edit: "/articles/edit/:id",
          show: "/articles/show/:id",
        },
      ]}
    >
      {/* Your routes and components */}
    </Refine>
  );
}
```

### With Authentication

```typescript
import { Refine } from "@refinedev/core";
import { AuthProvider } from "@refinedev/core";
import { gogoDataProvider } from "./dataProvider";

const authProvider: AuthProvider = {
  login: async ({ username, password }) => {
    const response = await fetch("http://localhost:8080/api/auth/login", {
      method: "POST",
      headers: { "Content-Type": "application/json" },
      body: JSON.stringify({ username, password }),
    });

    if (response.ok) {
      const { token } = await response.json();
      localStorage.setItem("token", token);
      return { success: true };
    }

    return {
      success: false,
      error: {
        message: "Login failed",
        name: "Invalid credentials",
      },
    };
  },
  logout: async () => {
    localStorage.removeItem("token");
    return { success: true };
  },
  check: async () => {
    const token = localStorage.getItem("token");
    return token ? { authenticated: true } : { authenticated: false };
  },
  onError: async (error) => {
    if (error.status === 401) {
      return { logout: true };
    }
    return { error };
  },
  getIdentity: async () => {
    const token = localStorage.getItem("token");
    if (!token) return null;

    // Fetch user info from your API
    const response = await fetch("http://localhost:8080/api/auth/me", {
      headers: { Authorization: `Bearer ${token}` },
    });

    if (response.ok) {
      return await response.json();
    }
    return null;
  },
};

function App() {
  return (
    <Refine
      dataProvider={gogoDataProvider({
        apiUrl: "http://localhost:8080/admin/api",
        getAccessToken: () => localStorage.getItem("token"),
      })}
      authProvider={authProvider}
      resources={[
        // Your resources
      ]}
    >
      {/* Your routes and components */}
    </Refine>
  );
}
```

### Resource Configuration

Resources should match the model names registered in your Gogo backend (lowercase):

```typescript
resources={[
  {
    name: "users", // Matches model name in Go (lowercase)
    list: "/users",
    create: "/users/create",
    edit: "/users/edit/:id",
    show: "/users/show/:id",
  },
]}
```

### Filter Operators

The data provider supports the following Refine filter operators:

- `eq` - Equals
- `ne` - Not equals
- `gt` - Greater than
- `gte` - Greater than or equal
- `lt` - Less than
- `lte` - Less than or equal
- `contains` - Contains (for strings)
- `in` - In array

### Sorting

Sorting is supported via Refine's `sorters` prop:

```typescript
<Refine
  // ...
  sorters={{
    initial: [
      {
        field: "created_at",
        order: "desc",
      },
    ],
  }}
/>
```

### Pagination

Pagination is automatically handled. The data provider uses:
- `page` - Current page number
- `page_size` - Items per page

## API Endpoints

The data provider expects the following API structure:

- `GET /admin/api/{resource}` - List resources
- `GET /admin/api/{resource}/{id}` - Get single resource
- `POST /admin/api/{resource}` - Create resource
- `PUT /admin/api/{resource}/{id}` - Update resource
- `DELETE /admin/api/{resource}/{id}` - Delete resource

### Response Format

List response:
```json
{
  "data": [...],
  "pagination": {
    "page": 1,
    "page_size": 20,
    "total": 100,
    "total_pages": 5
  }
}
```

Single resource response:
```json
{
  "data": {
    "id": "123",
    "name": "Example",
    ...
  }
}
```

## OpenAPI Integration

You can use the OpenAPI spec generated by Gogo to automatically configure Refine resources:

```typescript
import { gogoDataProvider } from "./dataProvider";

// Fetch OpenAPI spec
const openApiSpec = await fetch("http://localhost:8080/admin/api/openapi.json").then(r => r.json());

// Generate resources from OpenAPI spec
const resources = Object.keys(openApiSpec.components.schemas).map(schemaName => ({
  name: schemaName.toLowerCase(),
  list: `/${schemaName.toLowerCase()}`,
  create: `/${schemaName.toLowerCase()}/create`,
  edit: `/${schemaName.toLowerCase()}/edit/:id`,
  show: `/${schemaName.toLowerCase()}/show/:id`,
}));
```
